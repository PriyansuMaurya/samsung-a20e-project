# Agent instructions

## Commits

Never add AI attribution to a commit message. No "Generated with ..." lines, no `Co-Authored-By:` trailers naming an assistant, no emoji signature footers, no equivalent credits. A commit message ends at its own last line.

Follow the existing history: a single declarative subject line describing the change, for example `Preserve dashboard and terminal state across navigation`. Add a short body only when the reason for the change is not obvious from the subject.

Do not rewrite existing commits to add or remove attribution unless asked.
